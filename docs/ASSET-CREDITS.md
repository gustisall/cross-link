# CrossLink — kredit foto perlengkapan

Semua berkas berikut adalah foto nyata yang diperoleh dari Wikimedia Commons, disimpan lokal, dan tidak menggunakan generasi AI. Guru tetap perlu memverifikasi bahwa bentuk alat pada foto sesuai dengan kit sekolah. Foto kabel menunjukkan kabel UTP sebagai contoh pengenalan fisik, bukan bukti susunan crossover. Foto konektor menunjukkan konektor 8P8C yang telah dipasang pada kabel; gambar prosedur pemasangan dalam game adalah ilustrasi terpisah.

Turunan foto CC BY-SA tetap didistribusikan dengan CC BY-SA 3.0. Kredit ini tidak menyiratkan dukungan pembuat foto terhadap CrossLink. Metadata mesin tersedia di `public/assets/credits.json`, termasuk URL unduh asli, lisensi, dan perubahan. `scripts/fetch-assets.py` dapat menghasilkan ulang berkas dari sumber aslinya dengan Python dan Pillow; akses jaringan diperlukan hanya saat penyiapan aset, tidak saat memainkan game.
