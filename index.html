Buka CrossLink melalui launcher

File ini perlu dibuka melalui server lokal agar game dapat berjalan.

  1. Kembali ke folder game.
  2. Klik dua kali Start-CrossLink.cmd.
  3. Browser akan terbuka otomatis. Biarkan jendela server tetap terbuka selama bermain.

Jika server sudah berjalan, gunakan tombol ini:

Buka game CrossLink
